User guide

        
Plain steps. You do not need to know what a nonce is.

        
    
          
  1. Use MetaMask or Rabby on this page. Binance and some mobile wallets cannot sign from a website.
    2. 
          
  2. Add BlockDAG as a custom network: chain ID 1404, RPC https://rpc.welshdag.trade or https://rpc.blockdag.engineering, symbol BDAG.
    3. 
          
  3. Open this site, read the agreement, tap Connect wallet, approve chain 1404.
    4. 
          
  4. Wait for the blue/green box.
            
      
              
    • Green — no stuck send. Your next transfer can go out. Do not tap Vacate.
      • 
              
    • Orange/red — stuck send found. Tap Vacate. Approve a 0 BDAG send to yourself. You only pay gas.
      • 
            
    
          
    5. 
          
  5. After Vacate, wait about a minute, tap Check again. When the box turns green, you are done.
    6. 
          
  6. Keep the wallet on a community RPC. Do not use bdagscan for sending.
    7. 
        

        
If the wallet says method not found

        
Import the same account into MetaMask with the private key (not the phrase box). Send 0 BDAG to yourself. In Advanced, set the nonce to the slot number this page shows.
